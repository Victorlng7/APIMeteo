# ⛅ AppMétéo - Tracker Météorologique en Temps Réel

Une application web minimaliste et moderne permettant de consulter les conditions météorologiques de n'importe quelle ville en temps réel.

Ce projet a été développé dans le but de consolider mes compétences en requêtes asynchrones, manipulation du DOM et typage strict.

## ✨ Fonctionnalités

- **Recherche par ville** : Utilisation de l'API Geocoding pour convertir un nom de ville en coordonnées GPS.
- **Météo en temps réel** : Affichage de la température, de l'humidité, de la vitesse du vent et de la description via l'API OpenWeatherMap.

## 🛠️ Technologies Utilisées

- **HTML5 / CSS3** : Structure et style (Flexbox, variables CSS, effets de flou).
- **TypeScript** : Logique applicative, typage des données de l'API et gestion des événements.
- **OpenWeatherMap API** : Fournisseur des données géographiques et météorologiques.
